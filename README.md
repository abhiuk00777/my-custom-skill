# my-custom-skill

It is the simplest agent you can use in the project for the development , without any prior deep understanding of LLM's.

A custom AI agent skill designed to scaffold new projects, enforce architectural patterns, and generate boilerplate code according to company standards.

Choose whatever method below you like to start

XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX


Using GIT - if you want to see the detailed repo clone it 

git submodule add https://github.com/abhiuk00777/my-custom-skill

After the git Command  run the command below to set the AGENT

cp my-custom-skills/AGENTS.md ./AGENTS.md

Now you are ready to start using the claude in the best possible form.


XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX

Using Node on terminal 
npm install github:abhiuk00777/my-custom-skill

After the Npm Install Command  run the command below
cp -f node_modules/my-custom-skill/AGENTS.md ./

Now you are ready to start using the claude in the best possible form.
